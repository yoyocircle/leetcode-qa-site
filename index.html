LeetCode Python learning path¶

350 problems: 282 Medium and 68 Hard. Each lesson includes two or three Python approaches, hints, proofs, and complexity.

Study plan · Template categories · Practice by algorithm

Learning roadmap¶

Complete 80 Core problems before the 270 Extension problems. Within each phase, follow topic and catalog order. The three-digit prefix is the learning step; # identifies the LeetCode problem. Previous/next links follow this same sequence.

At five new problems per week, allow about 16 weeks for Core and 70 for the full path; ten per week gives about 35 weeks. Revisit the same problem with another data structure or algorithm during review.
