    337 打家劫舍 III¶

    快速複習：樹的後序處理 · 狀態機動態規劃

    題目¶

    選取樹節點使值總和最大，但任何父子邊兩端不可同時選取，回傳最大總和。

    提示¶

    1. 子樹結果取決於根是否被選。
    2. 選根時只能合併孫節點或略過孩子的狀態。
    展開解法、複雜度比較、證明與 Python 程式

    解法比較¶

    解法 時間 空間
    選取與略過狀態配對 O(n) O(n)
    以孫節點遞推最佳值 O(n) O(n)

    請先閱讀各解法的限制與輸入修改說明。教學基準解法可能超過題目要求的成本上限；第一種為預設實作。

    解法¶

    選取與略過狀態配對¶

    迭代後序儲存 (take,skip)。take 加根與兩個孩子的 skip；skip 則加兩孩子各自較好的狀態。

    以孫節點遞推最佳值¶

    每子樹保留單一最佳值，比較略過根並取孩子最佳值，或選根並取孫節點最佳值。

    正確性說明¶

    選取與略過狀態配對¶

    子樹唯一外部衝突是根有無被選。列出兩態就涵蓋全部合法選擇，而左右子樹最佳值可獨立相加。

    以孫節點遞推最佳值¶

    選根恰禁止其孩子，使孫節點問題互不相干；略過根則使兩個孩子問題不受限制。取兩者最大值涵蓋所有合法選擇。

    範例推演¶

    根 4、孩子 1 與 2，而 1 下有值 5 的孫節點，可選 4 與 5，總和 9。

    複雜度與常見錯誤¶

    選取與略過狀態配對：時間 O(n)；空間 O(n)。

    以孫節點遞推最佳值：時間 O(n)；空間 O(n)。

    樹不變。貪婪只選整個偶數或奇數層，可能漏掉不同深度混合的較佳選擇。迭代後序支援長鏈；兩模型都需要先完成後代狀態。

    Python 實作¶

    每個程式區塊都能獨立使用，並採用 LeetCode 的類別名稱。選一個貼入 Python3 編輯器；需要時已附共用節點定義。兩種語言共用完全相同的程式。

    1. 選取與略過狀態配對¶

    時間： O(n)

    空間： O(n)

    class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    """Approach: Take and skip state pairs
    Time: O(n)
    Space: O(n)
    """

    def rob(self, root: TreeNode | None) -> int:
        values = {None: (0, 0)}
        stack = [(root, False)] if root else []
        while stack:
            node, expanded = stack.pop()
            if expanded:
                left, right = values[node.left], values[node.right]
                values[node] = (node.val + left[1] + right[1], max(left) + max(right))
            else:
                stack.append((node, True))
                for child in (node.left, node.right):
                    if child:
                        stack.append((child, False))
        return max(values[root])

    2. 以孫節點遞推最佳值¶

    時間： O(n)

    空間： O(n)

    class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    """Approach: Best value with grandchild recurrence
    Time: O(n)
    Space: O(n)
    """

    def rob(self, root: TreeNode | None) -> int:
        best = {None: 0}
        stack = [(root, False)] if root else []
        while stack:
            node, expanded = stack.pop()
            if expanded:
                take = node.val
                for child in (node.left, node.right):
                    if child:
                        take += best[child.left] + best[child.right]
                best[node] = max(take, best[node.left] + best[node.right])
            else:
                stack.append((node, True))
                for child in (node.left, node.right):
                    if child:
                        stack.append((child, False))
        return best[root]
