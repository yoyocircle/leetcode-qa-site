解題前先選模式、說出不變量，再依輸入與輸出規格調整骨架。學習路線 提供順序，每份題解 都連回相關模板。

Python 範例使用 3.10 以上的標準庫。Node 代表題目提供的節點類別，feasible、neighbors 等回呼由你提供。這些是可重用骨架，邊界條件與輸出形狀仍須符合實際題目。

頻率表¶

使用可雜湊的摘要表示一組等價資料。計數能保留重複次數，集合不能。固定大小鍵值的雜湊表操作平均為常數時間，但建立或雜湊長鍵值也有成本。

from collections import defaultdict


def group_lowercase(words):
    groups = defaultdict(list)
    for word in words:
        counts = [0] * 26
        for char in word:
            counts[ord(char) - ord("a")] += 1
        groups[tuple(counts)].append(word)
    return list(groups.values())

不變量：每個桶恰好包含字元計數向量相同的單字。時間為 O(總字元數 + 26 × 單字數)，另計儲存鍵值及輸出的空間。

前後綴聚合¶

答案若由某位置之前與之後的所有元素組成，可計算不包含該位置的前綴與後綴。結合運算須滿足結合律並具有單位元素，不必有反運算。

def exclusive_products(nums):
    out = [1] * len(nums)
    prefix = 1
    for i, value in enumerate(nums):
        out[i] = prefix
        prefix *= value
    suffix = 1
    for i in range(len(nums) - 1, -1, -1):
        out[i] *= suffix
        suffix *= nums[i]
    return out

不變量：先使用累積值，再把目前元素合併進去，確保排除自身。時間 O(n)，輸出以外的輔助空間 O(1)。前後綴最大值也能構成接雨水題的 O(n) 空間基準解法。

雜湊集合連續段¶

尋找連續整數段時，只從不存在前一個整數的位置開始，避免重複掃描同一段長序列。

def longest_run(nums):
    values = set(nums)
    best = 0
    for start in values:
        if start - 1 in values:
            continue
        end = start
        while end in values:
            end += 1
        best = max(best, end - start)
    return best

不變量：每個相異整數恰好屬於一次掃描。平均時間 O(n)，空間 O(n)。走訪集合而非原始陣列，避免重複值造成重複起點。

雙指標¶

利用排序一次排除一整列或一整欄的配對候選。已排序陣列的兩數和若小於目標，便可排除目前左端點。

def sorted_pair(values, target):
    left, right = 0, len(values) - 1
    while left < right:
        total = values[left] + values[right]
        if total == target:
            return left, right
        if total < target:
            left += 1
        else:
            right -= 1
    return None

不變量：所有可能答案仍位於兩指標之間。排序後時間 O(n)、空間 O(1)。固定一個錨點可延伸為 3Sum，並略過重複錨點及成功配對後的重複端點。容器面積題移動較矮的一側；接雨水題結算已知邊界最大值較小的一側。每種移動規則都需要自己的排除證明。

滑動視窗¶

對符合單調預算上限的最長視窗，先擴張右端，再縮小到合法。對涵蓋所有需求的最短視窗，合法時持續縮小，並在移除左端字元前記錄候選。

def longest_unique(text):
    last = {}
    left = best = 0
    for right, char in enumerate(text):
        left = max(left, last.get(char, -1) + 1)
        last[char] = right
        best = max(best, right - left + 1)
    return best

不變量：此模板的視窗沒有重複字元，且左端永不後退。平均時間 O(n)，空間 O(字元集大小)。固定長度排列視窗使用計數，移除 right-width 的元素。字元替換須滿足 window_length-max_frequency<=k。最小涵蓋區間須記錄次數，不能只檢查字元是否存在。先存答案索引，最後再切片。

單調雙端佇列¶

移動視窗最大值只保留值遞減的候選。儲存索引以判斷過期；更新且值不小的元素會支配較舊候選。

from collections import deque


def window_maximum(nums, width):
    candidates, out = deque(), []
    for right, value in enumerate(nums):
        while candidates and candidates[0] <= right - width:
            candidates.popleft()
        while candidates and nums[candidates[-1]] <= value:
            candidates.pop()
        candidates.append(right)
        if right >= width - 1:
            out.append(nums[candidates[0]])
    return out

不變量：索引遞增、值遞減，隊首就是目前最大值。每個索引只進出一次，總時間 O(n)，輔助空間 O(width)。視窗寬度須符合輸入範圍。

堆疊¶

堆疊保存尚未完成的巢狀或循序工作。計算後綴表示式時，先取出右運算元，再取左運算元。

def evaluate_postfix(tokens, operations):
    stack = []
    for token in tokens:
        if token not in operations:
            stack.append(int(token))
            continue
        right, left = stack.pop(), stack.pop()
        stack.append(operations[token](left, right))
    return stack.pop()


def truncate_division(left, right):

二分搜尋¶

選定一種邊界慣例並持續維護。此半開區間搜尋找第一個至少等於 target 的值，插入位置可以等於 len(values)。

def lower_bound(values, target):
    left, right = 0, len(values)
    while left < right:
        middle = (left + right) // 2
        if values[middle] < target:
            left = middle + 1
        else:
            right = middle
    return left

不變量：left 之前的值都太小，right 及之後的值都滿足條件。時間 O(log n)、空間 O(1)。旋轉陣列可辨認已排序的一半，或比較 middle 與 right；簡單規則需要相異值。時間戳查詢可用 bisect_right 再減一。Python bisect 文件 定義左右插入邊界，key 參數自 Python 3.10 起提供。

二分分割¶

對兩個已排序陣列，在較短者搜尋切點，再由合併後左側的預定大小推得另一切點。

def median_partition(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    low, high = 0, m
    while low <= high:
        i = (low + high) // 2
        j = (m + n + 1) // 2 - i
        al = a[i - 1] if i else float("-inf")
        ar = a[i] if i < m else float("inf")
        bl = b[j - 1] if j else float("-inf")
        br = b[j] if j < n else float("inf")
        if al <= br and bl <= ar:
            if (m + n) % 2:
                return max(al, bl)
            return (max(al, bl) + min(ar, br)) / 2
        if al > br:
            high = i - 1
        else:
            low = i + 1

不變量：左側總長度固定；比較邊界以找到左側所有值不大於右側所有值的切點。輸入須已排序，合併長度須大於零。時間 O(log(min(m,n)+1))，空間 O(1)。

def can_reach(nums):

def minimum_jumps(nums):  # Destination is guaranteed reachable.

        if i == boundary:
            jumps += 1
            boundary = farthest
    return jumps

from collections import deque


def clone_graph(start, make_node):
    if start is None:
        return None
    copies = {start: make_node(start.val)}
    queue = deque([start])
    while queue:
        original = queue.popleft()
        for neighbor in original.neighbors:
            if neighbor not in copies:
                copies[neighbor] = make_node(neighbor.val)
                queue.append(neighbor)
            copies[original].neighbors.append(copies[neighbor])
    return copies[start]

環狀緩衝區¶

只儲存 head 與 size，以容量取模推得下一個插入位置，避免獨立頭尾旗標組合出矛盾狀態。

class RingQueue:
    def __init__(self, capacity):
        self.data = [0] * capacity
        self.head = 0
        self.size = 0

    def enqueue(self, value):
        if self.size == len(self.data):
            return False
        index = (self.head + self.size) % len(self.data)
        self.data[index] = value
        self.size += 1
        return True

    def dequeue(self):
        if self.size == 0:
            return False
        self.head = (self.head + 1) % len(self.data)
        self.size -= 1
        return True

    def front(self):
        return self.data[self.head] if self.size else -1

不變量：0<=size<=capacity，有效項目從 head 起連續占據 size 個環狀位置。容量為正，操作 O(1)，空間 O(capacity)。空／滿由 size 決定，因此環狀索引相等不會產生歧義。

LRU 快取¶

同時維護依鍵查詢及可移動的新舊順序。標準庫 OrderedDict 支援把既有鍵移至端點及移除最舊項目。

from collections import OrderedDict


class Cache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key, value):
        self.data[key] = value
        self.data.move_to_end(key)
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)

不變量：迭代順序由最久未使用到最近使用。操作平均 O(1)，空間 O(capacity)。更新值也會刷新新舊順序，查詢失敗則不會。手寫版本可用鍵到節點的字典，加頭尾哨兵的雙向鏈結串列。get/put 把節點摘下再插到 tail 前；淘汰時同時從兩種結構移除 head.next。

樹的走訪¶

中序走訪使用明確的祖先堆疊。層序走訪使用佇列，每層開始前固定佇列大小。

def inorder(root):
    stack = []
    current = root
    while current or stack:
        while current:
            stack.append(current)
            current = current.left
        current = stack.pop()
        yield current
        current = current.right

不變量：每次 pop 都是下一個中序節點。時間 O(n)、堆疊空間 O(h)。嚴格 BST 的中序序列嚴格遞增；第 k 小可計算 pop 次數。層序 BFS 時間 O(n)、空間 O(最大寬度)，每層最後一個節點構成右側視圖。LCA 可記錄父節點、收集其中一個目標的祖先，再讓另一目標向上找到第一個交集；比較物件身分。

先計算子節點，再計算父節點。帶有「已展開」狀態的明確堆疊可避開偏斜樹的遞迴深度限制。

def reduce_tree(root, combine):
    if root is None:
        return None
    values = {}
    stack = [(root, False)]
    while stack:
        node, expanded = stack.pop()
        if expanded:
            values[node] = combine(node.val, values.get(node.left), values.get(node.right))
            continue
        stack.append((node, True))
        if node.right:
            stack.append((node.right, False))
        if node.left:
            stack.append((node.left, False))
    return values[root]

不變量：執行 combine 時，左右子樹的結果都已存在。此通用版本時間 O(n)，儲存結果的空間 O(n)。最大路徑和的完整路徑可使用兩側收益，但傳給父節點的收益只能選一側。子收益至少取 0，全域答案初值則必須低於所有節點值。

樹的建構¶

前序走訪提供根節點；中序走訪指出左側子樹何時完成。此迭代重建要求節點值相異且兩個走訪序列一致。

def from_preorder_inorder(preorder, inorder, Node):
    values = iter(preorder)
    root = Node(next(values))
    stack = [root]
    index = 0
    for value in values:
        parent = stack[-1]
        child = Node(value)
        if parent.val != inorder[index]:
            parent.left = child
        else:
            while stack and stack[-1].val == inorder[index]:
                parent = stack.pop()
                index += 1
            parent.right = child
        stack.append(child)
    return root

不變量：堆疊是尚未結束的祖先路徑，index 指向下一個應結束的中序節點。時間 O(n)、輔助堆疊 O(h)，新節點 O(n)。輸入非空。也可用索引區間遞迴重建；但遞迴切片有複製成本，Python 呼叫深度也可能超限。

樹的序列化¶

def encode_tree(root):
    stack, tokens = [root], []
    while stack:
        node = stack.pop()
        if node is None:
            tokens.append("#")
            continue
        tokens.append(str(node.val))
        stack.append(node.right)
        stack.append(node.left)
    return ",".join(tokens)


def decode_tree(data, Node):
    tokens = iter(data.split(","))
    first = next(tokens)
    if first == "#":
        return None
    root = Node(int(first))
    slots = [(root, "right"), (root, "left")]
    for token in tokens:
        parent, side = slots.pop()
        child = None if token == "#" else Node(int(token))
        setattr(parent, side, child)
        if child is not None:
            slots.extend([(child, "right"), (child, "left")])
    return root

不變量：下一個 token 填入下一個前序子節點位置。編碼與解碼必須採用相同格式，解碼輸入假設由編碼器產生。整數有界時，時間 O(n)，輔助及編碼總空間 O(n)。空標記用來區分缺少左子節點與缺少右子節點。

堆積¶

保留最好的 k 個候選，並快速取得其中最差的一個。Python 的一般 heapq 操作使用最小堆積；在 Python 3.10 可用負優先值模擬最大堆積。

from heapq import heapify, heapreplace


def k_largest(values, k):
    heap = values[:k]
    heapify(heap)
    for i in range(k, len(values)):
        if values[i] > heap[0]:
            heapreplace(heap, values[i])
    return heap

不變量：堆積持有已處理值中最大的 k 個，k 須在 1..n 之間。時間 O(n log(k+1))、空間 O(k)；堆積並非完全排序。找最近 k 點可用負的距離平方，讓最遠點位於根。k 路合併每個串流保留一個頭項目，取出後補入後繼。堆積 tuple 中，不能排序的物件之前須放數字作為同值時的比較鍵。

頻率桶¶

頻率為不超過 n 的整數時，可依頻率分桶，不必排序所有值。

from collections import Counter


def most_frequent(nums, k):
    buckets = [[] for _ in range(len(nums) + 1)]
    for value, frequency in Counter(nums).items():
        buckets[frequency].append(value)
    out = []
    for frequency in range(len(nums), 0, -1):
        out.extend(buckets[frequency])
        if len(out) >= k:
            return out[:k]

不變量：由高到低的桶索引代表非遞增頻率。k 合法時，平均時間及輔助空間均為 O(n)。每個桶必須是獨立串列；把包含一個空串列的串列相乘會讓各桶共用物件。截止頻率有同值時須確認題目規則，本題所選集合保證唯一。

雙堆積¶

把串流分為較小一半的最大堆積與較大一半的最小堆積。前者大小等於後者或恰好多一個。

from heapq import heappop, heappush


class RunningMedian:
    def __init__(self):
        self.lower, self.upper = [], []

    def add(self, value):
        heappush(self.lower, -value)
        heappush(self.upper, -heappop(self.lower))
        if len(self.upper) > len(self.lower):
            heappush(self.lower, -heappop(self.upper))

    def median(self):  # At least one value has been added.
        if len(self.lower) > len(self.upper):
            return -self.lower[0]
        return (-self.lower[0] + self.upper[0]) / 2

不變量：較小半部的所有值不大於較大半部，且大小平衡。插入 O(log n)、取中位數 O(1)、空間 O(n)。讀取及移動負值表示的堆積元素時都要還原符號。相等的值可以出現在兩個堆積中。

圖的走訪¶

BFS 求無權圖的最少邊數。入列時就標記，避免多個父節點重複把同一節點加入佇列。

from collections import deque


def bfs_distances(starts, neighbors):
    distance = {node: 0 for node in starts}
    queue = deque(distance)
    while queue:
        node = queue.popleft()
        for child in neighbors(node):
            if child in distance:
                continue
            distance[child] = distance[node] + 1
            queue.append(child)
    return distance

不變量：佇列以非遞減距離處理。明確儲存的圖時間 O(V+E)、走訪空間 O(V)。同時擴散的多個起點都以距離 0 入列。Flood fill 可數連通元件；水流問題可反轉流向，從海岸邊界出發。隱含單字圖要計入字串建立成本，並清空已處理萬用字元桶。DFS 使用串列堆疊與相同發現規則，但第一次抵達不保證最短無權距離。

拓樸排序¶

Kahn 演算法移除沒有剩餘依賴的頂點。prerequisite->course 的邊讓 course 多一條入邊依賴。

from collections import deque


def topological_order(adjacency):
    degree = [0] * len(adjacency)
    for children in adjacency:
        for child in children:
            degree[child] += 1
    queue = deque(i for i, count in enumerate(degree) if count == 0)
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for child in adjacency[node]:
            degree[child] -= 1
            if degree[child] == 0:
                queue.append(child)
    return order if len(order) == len(adjacency) else []

不變量：degree 只計算來自未移除頂點的入邊。時間 O(V+E)，鄰接表以外空間 O(V)。輸出頂點不足證明存在環，也要初始化孤立頂點。嚴格遞增網格的邊從小值指向大值，不可能成環；固定大小的 BFS 分層數就是最長路徑長度。重複邊必須一致地計入與扣除。

並查集（Union Find）¶

無向邊逐一加入時追蹤連通元件。若兩端已有相同代表，這條邊便會成環。可按 size（元件元素數）或 rank（樹高上界）合併。以下兩版本都使用迭代式路徑折半，兩端原本已連通時回傳 False。

class DisjointSet:
    def __init__(self, count):
        self.parent = list(range(count))
        self.size = [1] * count

    def find(self, node):
        while node != self.parent[node]:
            self.parent[node] = self.parent[self.parent[node]]
            node = self.parent[node]
        return node

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True


class DisjointSetByRank:
    def __init__(self, count):
        self.parent = list(range(count))
        self.rank = [0] * count

    def find(self, node):
        while node != self.parent[node]:
            self.parent[node] = self.parent[self.parent[node]]
            node = self.parent[node]
        return node

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.rank[a] < self.rank[b]:
            a, b = b, a
        self.parent[b] = a
        if self.rank[a] == self.rank[b]:
            self.rank[a] += 1
        return True

不變量：每棵父節點樹代表一個元件；只有根的 size 有意義。初始化 O(V)、空間 O(V)，路徑壓縮搭配按 size 合併，每次操作攤銷 O(alpha(V))。搭配按 rank 合併具有相同界限。

低 rank 根接到高 rank 根；只有兩個不同根的 rank 相等時，才增加存活根的 rank。重複 union 不得增加 rank。壓縮會縮短路徑，因此 rank 是歷史樹高上界，不是現在高度，也不是元件大小。find 不降低 rank。沒有壓縮時，僅按 rank 合併的 find/union 最壞 O(log V)；壓縮後的界限是攤銷值，不代表每次都為最壞常數時間。

例如 union(0,1) 讓根 0 的 rank 變 1，union(2,3) 讓根 2 的 rank 變 1；再 union(0,2) 讓根 0 的 rank 變 2。find(3) 縮短到根 0 的路徑，但 rank 仍為 2。需要元件元素數時使用 size，rank 無法回答這個問題。本結構處理連通性，不處理有向環判定或最短路徑。

Dijkstra 最短路徑¶

對非負權重邊，用最小堆積維護暫定距離。之後若找到更短路，舊項目仍在堆積中；取出時略過過期項目。

from heapq import heappop, heappush


def shortest_distances(adjacency, start):
    distances = [float("inf")] * len(adjacency)
    distances[start] = 0
    heap = [(0, start)]
    while heap:
        distance, node = heappop(heap)
        if distance != distances[node]:
            continue
        for child, weight in adjacency[node]:
            candidate = distance + weight
            if candidate < distances[child]:
                distances[child] = candidate
                heappush(heap, (candidate, child))
    return distances

不變量：下一個未過期的最小距離可以確定；非負邊使尚未確定且距離更大的節點無法提供更短路。此延遲刪除版本時間 O(V + E log(E+2))，包含堆積項目的空間 O(V+E)。無限大代表不可達。零權重合法，負權重則破壞此證明。

歐拉路徑¶

每張有向機票都須用一次時，要找的是使用所有邊的歐拉路徑。Hierholzer 演算法在一個頂點的所有出邊都用完後才記錄它。

from collections import defaultdict


def itinerary(tickets, start):
    graph = defaultdict(list)
    for origin, destination in sorted(tickets, reverse=True):
        graph[origin].append(destination)
    stack, reversed_route = [start], []
    while stack:
        node = stack[-1]
        if graph[node]:
            stack.append(graph[node].pop())
        else:
            reversed_route.append(stack.pop())
    return reversed_route[::-1]

不變量：透過反向後序，把已走完的路段拼成使用所有邊的路徑。輸入須保證從 start 存在歐拉路徑。目的地反向排序後 pop 可先取字典序最小邊；後序處理了直接貪心輸出可能走入的死路。排序 O(E log E)，走訪時間及空間 O(E)。使用串列保留重複機票代表的多條邊。

最小生成樹¶

def spanning_tree_cost(vertex_count, weighted_edges, components):
    # components is a fresh DisjointSet(vertex_count).
    total = used = 0
    for weight, a, b in sorted(weighted_edges):
        if components.union(a, b):
            total += weight
            used += 1
    return total if used == vertex_count - 1 else None

from collections import deque


def shortest_state_path(starts, neighbors, goal):

        state = queue.popleft()

橋邊搜尋¶

無向簡單圖中，DFS 樹邊 parent->child 是橋，若且唯若孩子子樹無法另走到父節點或更早祖先。明確迭代器可保留遞迴 DFS 的進入／離開順序。

def graph_bridges(adjacency):
    size = len(adjacency)
    entered = [-1] * size
    low = [0] * size
    parent = [-1] * size
    clock = 0
    result = []
    for start in range(size):
        if entered[start] != -1:
            continue
        entered[start] = low[start] = clock
        clock += 1
        stack = [(start, iter(adjacency[start]))]
        while stack:
            node, edges = stack[-1]
            child = next(edges, None)
            if child is None:
                stack.pop()
                above = parent[node]
                if above != -1:
                    if low[node] > entered[above]:
                        result.append((above, node))
                    low[above] = min(low[above], low[node])
                continue
            if child == parent[node]:
                continue
            if entered[child] != -1:
                low[node] = min(low[node], entered[child])
                continue
            parent[child] = node
            entered[child] = low[child] = clock
            clock += 1
            stack.append((child, iter(adjacency[child])))
    return result

不變量：low[node] 是經過已完成 DFS 子樹、再至多走一條非父邊回邊可達的最早發現時間。時間 O(V+E)，走訪空間 O(V)。模板假設整數頂點且無平行邊；多重圖須用邊 ID 識別父邊。迭代版本可避開十萬節點長鏈的遞迴深度問題。

def minimum_coins(coins, amount):

動態規劃空間最佳化¶

空間壓縮會丟棄不再需要的舊列；位元遮罩狀態壓縮則是編碼子集合，兩者不同，也能一起使用。先寫出二維遞迴式並標明每次讀取屬於舊列或新列。0/1 背包 D[i][c] = max(D[i-1][c], D[i-1][c-w]+v) 只讀舊列，因此容量由大到小更新；完全背包改讀 D[i][c-w]，容量由小到大，允許重複取同一物品。以下函式求總重量不超過 capacity 的最大價值，要求容量非負、重量為正整數，允許空選擇。

def knapsack_once(items, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in items:
        for total in range(capacity, weight - 1, -1):
            dp[total] = max(dp[total], dp[total - weight] + value)
    return dp[capacity]


def knapsack_unbounded(items, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in items:
        for total in range(weight, capacity + 1):
            dp[total] = max(dp[total], dp[total - weight] + value)
    return dp[capacity]

不變量：降冪更新保留較小容量的舊列；升冪更新刻意讀取目前物品的新列。只有一件重量 2、價值 3 的物品且容量為 4 時，0/1 答案為 3，完全背包為 6；反轉方向會悄悄改變題意。時間皆為 O(物品數 × 容量)，空間由二維表降為 O(容量)。網格 DP 需要舊上方與新左方，故由左往右；編輯距離還需舊左上角，覆寫 dp[j] 前先存舊值，再交給下一格作為 diagonal，詳見字串動態規劃模板的可執行範例。每列重設左邊界。不同子序列則由右往左掃描目標，避免重複使用同一來源字元。恰好裝滿的版本須使用不可達哨兵，不能照抄此處全零初始化；計數時須先區分組合與有序序列，不能任意交換迴圈。若要重建選擇，可能仍需保留父節點或完整列。

from bisect import bisect_left


def increasing_length(values):
    tails = []
    for value in values:
        index = bisect_left(tails, value)
        if index == len(tails):
            tails.append(value)
        else:
            tails[index] = value
    return len(tails)

字串動態規劃¶

以兩個字串的前綴長度為座標。壓縮成單列時，覆寫目前格子前先保存舊對角線值。

def edit_distance(a, b):
    dp = list(range(len(b) + 1))
    for i, char_a in enumerate(a, 1):
        diagonal, dp[0] = dp[0], i
        for j, char_b in enumerate(b, 1):
            above = dp[j]
            if char_a == char_b:
                dp[j] = diagonal
            else:
                dp[j] = 1 + min(above, dp[j - 1], diagonal)
            diagonal = above
    return dp[-1]

不變量：above 屬於上一列，left 屬於目前列，diagonal 屬於上一列的前一欄。此模板時間 O(mn)、空間 O(n)。

題型 狀態與轉移 初始化或方向
最長共同子序列 D[i][j] 是兩前綴的最佳長度；同字元取對角線+1，否則 max(上,左)。 空前綴為 0；由左往右並保存對角線。
編輯距離 D[i][j] 是最少編輯數；不同字元取 1+min(刪除,插入,替換)。 D[i][0]=i，D[0][j]=j。
交錯字串 D[i][j] 表示目標前 i+j 字元可由兩來源各取 i、j 字元組成；可取任一匹配來源。 D[0][0]=True；先排除總長不符，各來源內部順序不能改。
相異子序列 D[i][j] 計算來源前 i 字元組出目標前 j 字元的方法數；跳過來源，字元相同時再加取用的方法。 空目標有一種方法；壓縮 j 須從右往左，避免同一來源字元重複使用。
正規表示式比對 D[i][j] 表示整個前綴匹配；一般字元用匹配對角線，字元加星號可跳過兩個模式符號，或從上方再匹配一個來源字元。 D[0][0]=True；空輸入可匹配連續的字元加星號。星號修飾前一個原子，必須匹配整串。

五種題型的前綴維度都使時間為 O(mn)。完整表空間 O(mn)，單列版本 O(n)。正規表示式的點消耗一個字元；星號與 Word Dictionary 的點不是同一種萬用規則。

def balloon_score(nums):
    values = [1, *nums, 1]
    size = len(values)
    dp = [[0] * size for _ in range(size)]
    for gap in range(2, size):
        for left in range(size - gap):
            right = left + gap
            dp[left][right] = max(
                dp[left][last] + dp[last][right] + values[left] * values[last] * values[right]

def two_transaction_profit(prices):
    buy1 = buy2 = float("-inf")
    sell1 = sell2 = 0
    for price in prices:
        buy1, sell1, buy2, sell2 = (
            max(buy1, -price),

            max(buy2, sell1 - price),

位元遮罩動態規劃¶

此處的狀態壓縮用整數位元遮罩編碼子集合，不是刪除舊 DP 列的空間最佳化。共有 2^n 個子集合，編碼不會消除指數成長。只有未來選擇完全相同的狀態才能合併：路徑問題通常還需記錄最後頂點，使用 (mask, last)，不能只用 mask。元素少時，用遮罩精確記錄已使用項目。正整數等和分組中，已用遮罩即可決定目前桶的餘數。

def equal_sum_groups(values, groups):
    total = sum(values)
    if total % groups:
        return False
    target = total // groups
    remainder = [-1] * (1 << len(values))
    remainder[0] = 0
    for mask in range(1 << len(values)):
        if remainder[mask] < 0:
            continue
        for index, value in enumerate(values):
            if mask & (1 << index) or remainder[mask] + value > target:
                continue
            following = mask | (1 << index)
            remainder[following] = (remainder[mask] + value) % target
    return remainder[-1] == 0

不變量：可達遮罩對應若干完整桶，加上儲存的當前餘數。元素與組數均為正，可整除時 target 才為正。時間 O(n×2^n)、空間 O(2^n)。遮罩標示項目身分，不同索引的重複值仍是不同項目。子集合和可行性也可用 Python 整數位元集合 bits |= bits << value，成本取決於位元集合長度。

矩陣快速冪¶

固定線性轉移反覆更新小型計數向量，且重複次數很多時適用。transition[destination][source] 表示一步從來源到目的狀態的方法數。矩陣須為方陣、大小須符合 counts、steps 非負、modulus 為正。

def advance_states(transition, counts, steps, modulus):
    size = len(counts)
    power = transition
    result = [count % modulus for count in counts]
    while steps:
        if steps & 1:
            result = [
                sum(power[row][col] * result[col] for col in range(size)) % modulus
                for row in range(size)
            ]
        power = [
            [
                sum(power[row][mid] * power[mid][col] for mid in range(size)) % modulus
                for col in range(size)
            ]
            for row in range(size)
        ]
        steps >>= 1
    return result

不變量：power 表示目前 2 的冪次數量的轉移；result 已套用消耗過的設定位元所對應的冪。平方讓轉移長度加倍，設定位元則把該區塊套到目前計數。不修改任何輸入串列。

transition=[[1,1],[1,0]]、counts=[1,0]，做四步得到 [5,3]，即相鄰費氏數。零步回傳初始向量各項對 modulus 取模。

d 個狀態、t>0 步時，時間 O(d³ log(t+1))、空間 O(d²)；零步成本 O(d)。這是算術操作次數；模數與小型 d 固定時，整數大小有界。t 適中時宜用滾動 DP，因矩陣乘法常數較大。確認轉移方向是目的狀態在列；長度 1 初始化需 n-1 次延伸，空字串初始化則需 n 次。

數位動態規劃（Digit DP）¶

依十進位逐位建立整數，只記錄會影響後續選擇的資訊。此範例計算 [0, bound] 中有效數字不重複的整數數量。狀態為 (position, used_mask, tight, started)：tight 表示前綴仍等於上界，started 區分補位零與真正的數字。終止條件明確將零本身計入一次。

from functools import cache


def count_unique_digits_up_to(bound):
    if bound < 0:
        return 0
    digits = tuple(map(int, str(bound)))

    @cache
    def visit(position, used_mask, tight, started):
        if position == len(digits):
            return 1  # Includes the all-padding path as the integer zero.
        limit = digits[position] if tight else 9
        total = 0
        for digit in range(limit + 1):
            next_tight = tight and digit == digits[position]
            if not started and digit == 0:
                total += visit(position + 1, used_mask, next_tight, False)
            elif not used_mask & (1 << digit):
                total += visit(position + 1, used_mask | (1 << digit), next_tight, True)
        return total

    return visit(0, 0, True, False)


def count_unique_digits_between(left, right):
    if left < 0 or right < left:
        raise ValueError("Require 0 <= left <= right")
    return count_unique_digits_up_to(right) - count_unique_digits_up_to(left - 1)

不變量：每個狀態計算在目前前綴限制下所有合法後綴。前導零不占用 bit 0；開始後的零是真正數字，不可重複。bound=20 時只有 11 不合法，答案為 20；bound=0 時答案為 1。若排除零，終止回傳改成 int(started)；其他性質也要明確定義零是否符合。不能把補位零標記為已使用，也不能從共用快取鍵刪掉 tight 或任何影響未來的狀態。快取建立在每次上界呼叫內，因此 R 與 L-1 不會互相污染。此處快取 tight 狀態是安全的，也可選擇只快取不受上界限制的狀態。閉區間使用 F(R)-F(L-1)，並定義 F(-1)=0，而不是減 F(L)。若有 D 位數、S 種性質狀態，時間上界 O(D × S × 10)，快取空間 O(D × S)，另有 O(D) 遞迴深度；此例 S 至多為 2^10 種遮罩乘常數個布林狀態。以上是算術操作次數，大整數另有位元成本；遞迴範例適用一般整數上界，而非任意長的十進位字串。數字總和或整除問題可替換或擴充遮罩為總和或餘數並調整終止判斷，但仍須保留 tight 與前導零語意。第 357 題是範圍 [0, 10^n-1] 的特例，此模板推廣到任意上下界。

前綴和¶

若區間結束處的前綴和為 p，目標和為 k，則需找更早的前綴和 p-k。輸入可以包含負數，不需要滑動視窗所依賴的和的單調性。

def count_target_intervals(nums, target):
    seen = {0: 1}
    prefix = answer = 0
    for value in nums:
        prefix += value
        answer += seen.get(prefix - target, 0)
        seen[prefix] = seen.get(prefix, 0) + 1
    return answer

不變量：查詢時，seen 只包含目前終點之前的前綴。平均時間 O(n)，空間 O(n)。求最長零和區間時，儲存最早索引而非頻率；先放入 0 對應 -1，且不覆寫首次索引。把二元陣列的 0 改視為 -1，即可尋找 0、1 數量相同的區間。

二維前綴和¶

多加一列與一欄零，讓所有矩形和都使用相同公式。半開查詢邊界能明確表達大小與空前綴。

def matrix_prefix(grid):
    rows, cols = len(grid), len(grid[0])
    prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
    for row in range(rows):
        for col in range(cols):
            prefix[row + 1][col + 1] = (
                grid[row][col] + prefix[row][col + 1] + prefix[row + 1][col] - prefix[row][col]
            )
    return prefix


def rectangle_sum(prefix, top, left, bottom, right):
    return prefix[bottom][right] - prefix[top][right] - prefix[bottom][left] + prefix[top][left]

不變量：prefix[r][c] 是前 r 列、前 c 欄的總和。建構時間與空間 O(rows×cols)，每次合法矩形查詢 O(1)。目標和子矩陣可固定兩個列邊界，壓縮各欄總和，再套用一維前綴頻率法。

樹狀陣列（Fenwick Tree）¶

一基索引 i 的節點摘要以 i 結尾、長度 i & -i 的區間。更新沿包含它的區間往上走；前綴查詢逐次移除最後一段已覆蓋區間。

class Fenwick:
    def __init__(self, size):
        self.tree = [0] * (size + 1)

    def add(self, index, delta):  # 1 <= index < len(tree)
        while index < len(self.tree):
            self.tree[index] += delta
            index += index & -index

    def prefix(self, index):  # Sum of positions 1..index; index 0 is valid.
        total = 0
        while index:
            total += self.tree[index]
            index -= index & -index
        return total

每次更新／查詢 O(log n)，空間 O(n)。區間和為 prefix(right)-prefix(left-1)。索引是任意值時可座標壓縮；壓縮只保留順序，不保留距離。數嚴格較小值時，先查 rank-1，再插入目前 rank。更新索引 0 不合法，會使此迴圈無法前進。

線段樹（Segment Tree）¶

每個區間儲存符合結合律的聚合值。此迭代總和樹把葉節點放在 n..2n 的半開範圍，查詢也採半開區間。

class SumTree:
    def __init__(self, values):
        self.size = len(values)
        self.tree = [0] * self.size + list(values)
        for node in range(self.size - 1, 0, -1):
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]

    def assign(self, index, value):
        node = index + self.size
        self.tree[node] = value
        while node > 1:
            node //= 2
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]

    def query(self, left, right):
        left, right = left + self.size, right + self.size
        total = 0
        while left < right:
            if left & 1:
                total += self.tree[left]
                left += 1
            if right & 1:
                right -= 1
                total += self.tree[right]
            left //= 2
            right //= 2
        return total

非空輸入的建構時間與空間為 O(n)，更新／查詢 O(log n)。內部節點維持兩個孩子的總和。區間加值／區間最大值需要不同聚合值與 lazy propagation；座標範圍極大時，可動態配置實際需要的節點，不必建完整座標陣列。

掃描線¶

把區間轉成起點／終點事件，按座標處理。半開區間在觀察活躍數之前，要合併相同座標的所有變化。

from collections import defaultdict


def peak_overlap(intervals):
    changes = defaultdict(int)
    for start, end in intervals:
        changes[start] += 1
        changes[end] -= 1
    active = peak = 0
    for position in sorted(changes):
        active += changes[position]
        peak = max(peak, active)
    return peak

不變量：active 是覆蓋下一段座標區間的事件數。時間 O(n log n)、空間 O(n)。天際線要追蹤活躍的最大高度而非數量，可用帶過期資訊的堆積或分治。相同 x 必須一起處理，避免輸出不存在的中間高度變化。

有序區間¶

互不重疊的半開區間保持排序時，新預約只可能與插入位置的前驅或後繼衝突。

from bisect import bisect_left


def book_disjoint(events, start, end):
    index = bisect_left(events, (start, end))
    if index and events[index - 1][1] > start:
        return False
    if index < len(events) and events[index][0] < end:
        return False
    events.insert(index, (start, end))
    return True

不變量：events 有序且互不重疊，輸入預約滿足 start<end。搜尋 O(log n)，但 Python 串列插入 O(n)，空間 O(n)。閉合整數連續段應合併相鄰值，條件變為 next_start<=previous_end+1；不能直接把行事曆端點規則套到整數段摘要。

合併排序計數¶

合併已排序的兩半時，跨半部關係可用單調掃描計算。此模板計算逆序對且不修改輸入。

def inversion_count(values):
    def visit(items):
        if len(items) < 2:
            return items[:], 0
        middle = len(items) // 2
        left, first = visit(items[:middle])
        right, second = visit(items[middle:])
        merged = []
        i = j = 0
        count = first + second
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i])
                i += 1
            else:
                count += len(left) - i
                merged.append(right[j])
                j += 1
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged, count

    return visit(values)[1]

時間 O(n log n)，尖峰輔助空間 O(n)。跨切點的嚴格逆序對，在右值先於較大左值被合併時恰好計入一次。區間和計數可排序前綴和，維護 lower<=right_prefix-left_prefix<=upper 的兩個單調邊界。答案屬於各原始位置時，要保留原索引。

前綴函數（KMP）¶

前綴函數記錄每個已處理前綴中，既是前綴又是後綴的最長真前綴長度。先重用上一個 border，再嘗試更短者。

def prefix_function(text):
    prefix = [0] * len(text)
    for index in range(1, len(text)):
        length = prefix[index - 1]
        while length and text[index] != text[length]:
            length = prefix[length - 1]
        if text[index] == text[length]:
            length += 1
        prefix[index] = length
    return prefix

不變量：length 是新字元之前那段前綴的候選 border 長度；失配時沿已證明的短 border 回退。長度增加與減少可攤銷，總時間 O(n)、空間 O(n)。非空字串的 text[:prefix[-1]] 即最長真 border；前後綴可以重疊。KMP 掃描另一字串時也使用相同失配連結。

Z 函數¶

i>0 時，Z[i] 是整串與從 i 開始的後綴之共同前綴長度；此慣例保留 Z[0]=0。重用目前最靠右已知匹配區間內的結果。

def z_function(text):
    z = [0] * len(text)
    left = right = 0
    for index in range(1, len(text)):
        if index <= right:
            z[index] = min(right - index + 1, z[index - left])
        while index + z[index] < len(text) and text[z[index]] == text[index + z[index]]:
            z[index] += 1
        if index + z[index] - 1 > right:
            left, right = index, index + z[index] - 1
    return z

不變量：text[left:right+1] 與等長前綴相同，且具有目前已知最遠右端。新的比較只擴張右端，總時間 O(n)、空間 O(n)。真 border 的起點 i>0 且 i+Z[i]==n。Z 與前綴函數都是確定性方法，沒有雜湊碰撞風險。

def read_unsigned(text, index):
    value = 0
    start = index
    while index < len(text) and "0" <= text[index] <= "9":
        value = value * 10 + ord(text[index]) - ord("0")
        index += 1
    if index == start:

位元運算¶

先定義字寬及有號數解讀方式。Python 整數不會在 32 位元溢位，有號字演算法須明確遮罩中間狀態。

def signed_word_add(a, b, width=32):
    mask = (1 << width) - 1
    a, b = a & mask, b & mask
    while b:
        a, b = (a ^ b) & mask, ((a & b) << 1) & mask
    sign = 1 << (width - 1)
    return a if a < sign else a - (1 << width)

XOR 是不含進位的和，AND 左移一位是進位。迴圈使用 O(width) 次固定字寬操作與 O(1) 個整數儲存。最低有效位可用 value & -value；區間 AND 保留共同高位前綴。成對數中有兩個單獨值時，先全部 XOR，再用其中一個不同位元把兩個值分到不同組。任意大整數操作另有位元成本。

整數運算¶

用平方把大指數反覆減半，不要對指數的每一單位都乘一次。

def nonnegative_power(base, exponent):
    result = 1
    while exponent:
        if exponent & 1:
            result *= base
        base *= base
        exponent >>= 1
    return result

不變量：result × base 的剩餘指數次方等於目標。非負整數指數需 O(log(exponent+1)) 次算術操作及 O(1) 輔助變數；允許負指數時使用倒數。精確整數除法可減去位移後的除數，朝零截斷須還原符號。階乘尾零數只需數因數 5：floor(n/5)+floor(n/25)+…，不必先算階乘。

隨機抽樣¶

蓄水池抽樣不儲存所有位置，就能在符合條件的項目中均勻選取。RNG 由外部傳入，測試可控制其狀態。

def reservoir_index(values, target, rng):
    answer = None
    matches = 0
    for index, value in enumerate(values):
        if value != target:
            continue
        matches += 1
        if rng.randrange(matches) == 0:
            answer = index
    return answer

遇到第 t 個匹配後，每個匹配的機率都是 1/t：舊選擇以 (t-1)/t 保留，新匹配以 1/t 取代。查詢時間 O(n)、空間 O(1)。預先建立位置表可用 O(n) 空間換 O(1) 抽樣。Fisher-Yates 每次交換從剩餘前綴均勻選取。隨機集合使用密集陣列、索引表與交換刪除；允許重複值時需追蹤每次出現的索引。只測輸出值合法不能證明均勻性，機率證明也是正確性的一部分。

Python 成本提醒¶

  • list.append 攤銷 O(1)；刪除索引 0 會搬移元素，隊首操作請用 deque。
  • 字串與串列切片會複製；新字串雜湊也會讀字元。Word Break、Word Ladder 要納入這些成本。
  • 排序副本與 Python 排序工作空間可能額外使用 O(n) 記憶體。
  • 獨立的巢狀串列使用 comprehension 建立；重複參照同一內層串列會讓多列一起被改動。
  • 堆積同值時仍須可比較，在節點物件之前放唯一數字索引。堆積順序不等於完整排序。
  • 字典與集合對小鍵值提供平均常數查找；依不變量選擇頻率、最早索引或物件身分。
  • 本文算術分析採常見面試的有界數值模型；Python 超大整數成本依位元長度增加。
  • 合法樹、圖、網格路徑可能超過遞迴限制時優先迭代；深度有界的回溯可保留遞迴。
