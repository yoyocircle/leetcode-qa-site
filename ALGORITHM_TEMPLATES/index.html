Python interview algorithm templates¶

Use this as a review sheet before solving a problem. Choose a pattern, state its invariant, then adapt the skeleton to the problem's input and output contract. The roadmap gives the study order; each problem writeup links back to its relevant sections.

Python snippets use standard-library APIs available in Python 3.10+. A name such as Node denotes the node class supplied by the problem; callback parameters such as feasible or neighbors are functions you provide. These are reusable skeletons, so boundary conditions and output shape still need to match the particular problem.

Frequency maps¶

Use a hashable summary as the identity of a group. Counts preserve multiplicity; a set does not. Expected hash-map operations take constant time for bounded-size keys, but constructing or hashing a long key has its own cost.

from collections import defaultdict


def group_lowercase(words):
    groups = defaultdict(list)
    for word in words:
        counts = [0] * 26
        for char in word:
            counts[ord(char) - ord("a")] += 1
        groups[tuple(counts)].append(word)
    return list(groups.values())

Invariant: each bucket contains exactly the words with its count vector. Cost: O(total characters + 26 * word count), plus stored keys and output. Practice: 49 Group Anagrams.

Prefix aggregates¶

When an answer combines everything strictly before and after a position, compute exclusive prefixes and suffixes. The combine operation must have an identity and be associative; it need not have an inverse.

def exclusive_products(nums):
    out = [1] * len(nums)
    prefix = 1
    for i, value in enumerate(nums):
        out[i] = prefix
        prefix *= value
    suffix = 1
    for i in range(len(nums) - 1, -1, -1):
        out[i] *= suffix
        suffix *= nums[i]
    return out

Invariant: update the running aggregate after using it, to exclude the current position. O(n) time and O(1) auxiliary state beyond output. Prefix/suffix maxima also give a simple O(n)-space baseline for rain water. Practice: 238 Product of Array Except Self.

Hash set runs¶

For consecutive integer runs, begin only where the predecessor is absent. Otherwise the same long run may be scanned repeatedly.

def longest_run(nums):
    values = set(nums)
    best = 0
    for start in values:
        if start - 1 in values:
            continue
        end = start
        while end in values:
            end += 1
        best = max(best, end - start)
    return best

Invariant: each distinct integer belongs to exactly one scan. Expected O(n) time and O(n) space. Iterate over the set to avoid repeated duplicate starts. Practice: 128 Longest Consecutive Sequence.

Prefix sums¶

For an interval ending at the current prefix p, a target sum k requires an earlier prefix p-k. Negative input values are allowed; monotone-sum window logic is not required.

def count_target_intervals(nums, target):
    seen = {0: 1}
    prefix = answer = 0
    for value in nums:
        prefix += value
        answer += seen.get(prefix - target, 0)
        seen[prefix] = seen.get(prefix, 0) + 1
    return answer

Invariant: seen contains only prefixes before the current endpoint when queried. Expected O(n) time and O(n) space. For a longest zero-sum interval, store the earliest index instead of a frequency, seed 0 at -1, and never overwrite that first index. Convert binary zeros to -1 for equal-zero/one counts. Practice: 560 Subarray Sum Equals K, 525 Contiguous Array.

Two pointers¶

Use ordering to eliminate a whole row or column of pair candidates. For sorted pair sums, a sum below target rules out the current left endpoint.

def sorted_pair(values, target):
    left, right = 0, len(values) - 1
    while left < right:
        total = values[left] + values[right]
        if total == target:
            return left, right
        if total < target:
            left += 1
        else:
            right -= 1
    return None

Invariant: every possible answer still lies between the pointers. O(n) time and O(1) space once sorted. Fix an anchor to extend this to 3Sum; skip repeated anchors and successful endpoint values. For container area, move the shorter height. For trapped water, settle the side with the smaller known boundary maximum. These movement rules require their own elimination argument. Practice: 15 3Sum, 42 Trapping Rain Water.

Sliding windows¶

For longest windows with at most a monotone budget, expand right, then shrink until valid. For shortest windows containing requirements, shrink while valid and record each valid candidate before removing its left character.

def longest_unique(text):
    last = {}
    left = best = 0
    for right, char in enumerate(text):
        left = max(left, last.get(char, -1) + 1)
        last[char] = right
        best = max(best, right - left + 1)
    return best

Invariant: this concrete window has no duplicate characters and left never moves backward. Expected O(n) time and O(alphabet size) space. Fixed-size permutations use counts and remove index right-width. Character replacement needs window_length-max_frequency<=k. Minimum cover needs occurrence counts, not just distinct-letter membership. Store result indices and slice at the end. Practice: 3 Longest Substring, 76 Minimum Window Substring.

Monotonic deque¶

Retain decreasing-value candidates for a moving-window maximum. Store indices for expiration; a newer equal-or-larger value dominates an older candidate.

from collections import deque


def window_maximum(nums, width):
    candidates, out = deque(), []
    for right, value in enumerate(nums):
        while candidates and candidates[0] <= right - width:
            candidates.popleft()
        while candidates and nums[candidates[-1]] <= value:
            candidates.pop()
        candidates.append(right)
        if right >= width - 1:
            out.append(nums[candidates[0]])
    return out

Invariant: indices increase and their values decrease; the front is the current maximum. O(n) total time because each index enters and leaves once; O(width) auxiliary space. The width must be valid. Practice: 239 Sliding Window Maximum.

Stacks¶

A stack holds unresolved nested or sequential work. Postfix evaluation consumes the right operand first, then the left operand.

def evaluate_postfix(tokens, operations):
    stack = []
    for token in tokens:
        if token not in operations:
            stack.append(int(token))
            continue
        right, left = stack.pop(), stack.pop()
        stack.append(operations[token](left, right))
    return stack.pop()


def truncate_division(left, right):
    value = abs(left) // abs(right)
    return -value if (left < 0) != (right < 0) else value

Invariant: each stack item is a completed expression waiting to be consumed. O(n) time and O(n) space with bounded numbers. Supply a mapping of the four operators to operations; division by zero is excluded. For MinStack, pair every value with the minimum at that depth so pop restores the old minimum. Monotonic stack¶

Keep unresolved indices whose values are nonincreasing. A strictly greater incoming value resolves all smaller values on top.

def next_greater_distances(values):
    waiting = []
    out = [0] * len(values)
    for i, value in enumerate(values):
        while waiting and values[waiting[-1]] < value:
            previous = waiting.pop()
            out[previous] = i - previous
        waiting.append(i)
    return out

Invariant: no waiting index has seen a greater value yet. O(n) amortized total time and O(n) space. Equality handling depends on the question's strictness. Greedy ordering¶

Prove that the chosen next item can replace an optimal solution's next item. For compatible intervals, earliest finishing leaves the most room.

def maximum_compatible(intervals):
    end = float("-inf")
    kept = 0
    for start, finish in sorted(intervals, key=lambda item: item[1]):
        if start >= end:
            end = finish
            kept += 1
    return kept

Invariant: among ways to keep this many intervals, the greedy end is no later. O(n log n) time and O(n) sorting space. Endpoint contact is allowed in this scheduling variant. Binary search¶

Choose one bound convention and preserve it. This half-open search finds the first value at least target, including an insertion position equal to len(values).

def lower_bound(values, target):
    left, right = 0, len(values)
    while left < right:
        middle = (left + right) // 2
        if values[middle] < target:
            left = middle + 1
        else:
            right = middle
    return left

Invariant: all indices below left are too small, and all indices at or above right satisfy the predicate. O(log n) time, O(1) space. For rotated arrays, identify the sorted half or compare middle with right; distinct values are needed for the simple rule. For timestamp lookup, use bisect_right then subtract one. The Python bisect documentation defines left/right insertion boundaries; its key parameter is available from 3.10. Practice: 33 Rotated Search, 981 Time Based Store.

Binary search on the answer¶

Search a monotone feasibility predicate when the output is a minimum valid capacity, speed, threshold, or time. Ensure the initial high endpoint is feasible.

def first_feasible(low, high, feasible):
    while low < high:
        middle = (low + high) // 2
        if feasible(middle):
            high = middle
        else:
            low = middle + 1
    return low

Invariant: the first feasible answer remains in the inclusive [low,high] range. Cost is O(predicate_cost * log(search_range+1)); state is O(1) beyond the predicate. Binary search partitions¶

For two sorted arrays, search a cut in the shorter array and derive the other cut from the desired combined left-side size.

def median_partition(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    low, high = 0, m
    while low <= high:
        i = (low + high) // 2
        j = (m + n + 1) // 2 - i
        al = a[i - 1] if i else float("-inf")
        ar = a[i] if i < m else float("inf")
        bl = b[j - 1] if j else float("-inf")
        br = b[j] if j < n else float("inf")
        if al <= br and bl <= ar:
            if (m + n) % 2:
                return max(al, bl)
            return (max(al, bl) + min(ar, br)) / 2
        if al > br:
            high = i - 1
        else:
            low = i + 1

Invariant: left size is fixed; the comparisons locate a cut with every left value at most every right value. Inputs must be sorted and combined length positive. O(log(min(m,n)+1)) time and O(1) space. Practice: 4 Median of Two Sorted Arrays.

Greedy reach¶

When reachable indices form a prefix, one farthest boundary summarizes them. For minimum jumps, treat reachable prefixes as compressed BFS layers.

def can_reach(nums):
    farthest = 0
    for i, step in enumerate(nums):
        if i > farthest:
            return False
        farthest = max(farthest, i + step)
    return True


def minimum_jumps(nums):  # Destination is guaranteed reachable.
    jumps = boundary = farthest = 0
    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])
        if i == boundary:
            jumps += 1
            boundary = farthest
    return jumps

Invariant: only reachable positions extend reach; each completed layer uses one more jump. O(n) time and O(1) space. Exclude the destination from the jumping loop to avoid an extra jump. Practice: 55 Jump Game, 45 Jump Game II.

Linked lists¶

Save a successor before overwriting a link. Dummy predecessors turn head removal and empty output construction into ordinary link operations.

def reverse(head):
    previous = None
    while head:
        following = head.next
        head.next = previous
        previous, head = head, following
    return previous


def remove_nth(head, n, Node):  # n is valid.
    dummy = Node(0, head)
    slow = fast = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:
        slow, fast = slow.next, fast.next
    slow.next = slow.next.next
    return dummy.next

Reverse invariant: previous is the reversed processed prefix; head begins the remaining original suffix. Gap invariant: fast stays n links ahead of slow. Object copying¶

Use original object identity as the key, and allocate a copy before traversing edges that can cycle. Values alone are not an identity.

from collections import deque


def clone_graph(start, make_node):
    if start is None:
        return None
    copies = {start: make_node(start.val)}
    queue = deque([start])
    while queue:
        original = queue.popleft()
        for neighbor in original.neighbors:
            if neighbor not in copies:
                copies[neighbor] = make_node(neighbor.val)
                queue.append(neighbor)
            copies[original].neighbors.append(copies[neighbor])
    return copies[start]

Invariant: every discovered original has exactly one allocated copy; copied edges always point to copies. Expected O(V+E) time and O(V) map/queue space, plus output. For random-pointer lists, allocate all copies in one pass and wire next/random through the map in a second pass, with None mapped to None. Practice: 133 Clone Graph, 138 Copy List.

Tree traversal¶

Inorder uses an explicit ancestor stack. Level order uses a queue and freezes its size before processing each depth.

def inorder(root):
    stack = []
    current = root
    while current or stack:
        while current:
            stack.append(current)
            current = current.left
        current = stack.pop()
        yield current
        current = current.right

Invariant: each pop is the next inorder node. O(n) time and O(h) stack space. A strict BST has a strictly increasing inorder sequence; kth-smallest counts pops. Level BFS takes O(n) time and O(width) space; its final node at each level is the right-side view. For LCA, record parent references, collect one target's ancestors, and walk the other upward to its first match. Use identity. Practice: 98 Validate BST, 236 Lowest Common Ancestor.

Tree postorder¶

Compute children before parents. An explicit expanded-state stack avoids recursion limits on skewed trees.

def reduce_tree(root, combine):
    if root is None:
        return None
    values = {}
    stack = [(root, False)]
    while stack:
        node, expanded = stack.pop()
        if expanded:
            values[node] = combine(node.val, values.get(node.left), values.get(node.right))
            continue
        stack.append((node, True))
        if node.right:
            stack.append((node.right, False))
        if node.left:
            stack.append((node.left, False))
    return values[root]

Invariant: both child results exist when combine runs. This general version uses O(n) time and O(n) stored results. For maximum path sum, a complete path may use both child gains, while the gain offered to the parent uses only one. Clamp child gains at zero, but initialize the global answer below all node values. Practice: 124 Maximum Path Sum.

Tree construction¶

Preorder introduces roots; inorder identifies when their left side is finished. Distinct values and consistent traversals make this iterative reconstruction valid.

def from_preorder_inorder(preorder, inorder, Node):
    values = iter(preorder)
    root = Node(next(values))
    stack = [root]
    index = 0
    for value in values:
        parent = stack[-1]
        child = Node(value)
        if parent.val != inorder[index]:
            parent.left = child
        else:
            while stack and stack[-1].val == inorder[index]:
                parent = stack.pop()
                index += 1
            parent.right = child
        stack.append(child)
    return root

Invariant: the stack is the unfinished ancestor path; index is the next inorder node to close. O(n) time, O(h) auxiliary stack, and O(n) new nodes. The input is nonempty. Recursive index-range reconstruction is another option, but recursive slicing adds copying and Python's stack depth can become a limit. Practice: 105 Construct Binary Tree.

Tree serialization¶

Record shape as well as values. Here is a preorder skeleton with explicit null slots; the problem lesson uses a breadth-first format instead.

def encode_tree(root):
    stack, tokens = [root], []
    while stack:
        node = stack.pop()
        if node is None:
            tokens.append("#")
            continue
        tokens.append(str(node.val))
        stack.append(node.right)
        stack.append(node.left)
    return ",".join(tokens)


def decode_tree(data, Node):
    tokens = iter(data.split(","))
    first = next(tokens)
    if first == "#":
        return None
    root = Node(int(first))
    slots = [(root, "right"), (root, "left")]
    for token in tokens:
        parent, side = slots.pop()
        child = None if token == "#" else Node(int(token))
        setattr(parent, side, child)
        if child is not None:
            slots.extend([(child, "right"), (child, "left")])
    return root

Invariant: the next token fills the next preorder child slot. Encode/decode must use the same format, and decoding expects encoder-produced input. O(n) time and O(n) total auxiliary/encoding space with bounded integer values. Null markers distinguish a missing left child from a missing right child. Practice: 297 Serialize and Deserialize.

Heaps¶

Retain the k best candidates and expose the worst retained candidate. Python's heapq uses a min-heap for its ordinary heap operations; negated priorities provide a max-heap on Python 3.10.

from heapq import heapify, heapreplace


def k_largest(values, k):
    heap = values[:k]
    heapify(heap)
    for i in range(k, len(values)):
        if values[i] > heap[0]:
            heapreplace(heap, values[i])
    return heap

Invariant: the heap holds the k largest processed values. Valid k is 1..n. O(n log(k+1)) time and O(k) space; the heap is not fully sorted. For k closest, use negative squared distances so the farthest is the root. For k-way merge, keep one head per stream and replace the popped head with its successor. Frequency buckets¶

When frequency is an integer bounded by n, bucket values by that frequency instead of sorting them.

from collections import Counter


def most_frequent(nums, k):
    buckets = [[] for _ in range(len(nums) + 1)]
    for value, frequency in Counter(nums).items():
        buckets[frequency].append(value)
    out = []
    for frequency in range(len(nums), 0, -1):

Two heaps¶

Partition a stream into a lower max-heap and an upper min-heap. Keep lower's size equal to upper's or larger by exactly one.

from heapq import heappop, heappush


class RunningMedian:
    def __init__(self):
        self.lower, self.upper = [], []

    def add(self, value):
        heappush(self.lower, -value)
        heappush(self.upper, -heappop(self.lower))
        if len(self.upper) > len(self.lower):
            heappush(self.lower, -heappop(self.upper))

    def median(self):  # At least one value has been added.
        if len(self.lower) > len(self.upper):
            return -self.lower[0]
        return (-self.lower[0] + self.upper[0]) / 2

Invariant: every lower value is at most every upper value, with balanced sizes. Insertion O(log n), median O(1), storage O(n). Negation applies on both reads and moves. Equal values may belong to both heaps. Practice: 295 Median from Stream.

LRU cache¶

Keep direct key lookup and movable recency order. In the standard library, OrderedDict supports moving an existing key to an endpoint and removing the oldest item.

from collections import OrderedDict


class Cache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key, value):
        self.data[key] = value
        self.data.move_to_end(key)
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)

Invariant: iteration order is oldest use to newest use. Expected O(1) per operation and O(capacity) storage. Updating a value refreshes recency; misses do not. For a manual implementation, use a dictionary from key to node and a doubly linked list with head/tail sentinels. Get and put detach the node and append it before tail; eviction removes head.next from both structures. Practice: 146 LRU Cache.

Backtracking¶

Enumerate choices when each solution needs its own sequence of decisions. State is local to one path and must be restored after each branch.

def enumerate_paths(state, choices, apply, undo, complete, emit):
    def visit():
        if complete(state):
            emit(state)  # emit must save an independent snapshot.
            return
        for choice in choices(state):
            apply(state, choice)
            visit()
            undo(state, choice)

    visit()

Invariant: state describes exactly the current path, and undo restores the parent state. Cost is the explored search tree plus output-copy work; auxiliary space depends on maximum depth and path state. For combinations use increasing indices; for reusable candidates recurse at the same index. Permutations track unused indices. Grid word search uses path-local cells; queens use occupied columns and both diagonal sets. Repeated states across different paths need care before caching. Graph traversal¶

BFS finds shortest edge counts in an unweighted graph. Mark a node when it is enqueued so multiple parents cannot enqueue it repeatedly.

from collections import deque


def bfs_distances(starts, neighbors):
    distance = {node: 0 for node in starts}
    queue = deque(distance)
    while queue:
        node = queue.popleft()
        for child in neighbors(node):
            if child in distance:
                continue
            distance[child] = distance[node] + 1
            queue.append(child)
    return distance

Invariant: the queue is processed in nondecreasing distance. O(V+E) time and O(V) traversal space for explicitly represented graphs. Seed all sources at distance zero for simultaneous spread. Flood fill counts connected components; reverse a water-flow relation to start from ocean borders. In implicit word graphs, account for string construction and clear processed wildcard buckets. DFS uses a list stack and the same discovery rule, but does not find shortest unweighted distances by first arrival. Practice: 994 Rotting Oranges, 417 Pacific Atlantic, 127 Word Ladder.

Topological sort¶

Kahn's algorithm removes dependency-free vertices. An edge prerequisite->course contributes one incoming dependency to the course.

from collections import deque


def topological_order(adjacency):
    degree = [0] * len(adjacency)
    for children in adjacency:
        for child in children:
            degree[child] += 1
    queue = deque(i for i, count in enumerate(degree) if count == 0)
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for child in adjacency[node]:
            degree[child] -= 1
            if degree[child] == 0:
                queue.append(child)
    return order if len(order) == len(adjacency) else []

Invariant: degree counts only incoming edges from unremoved vertices. O(V+E) time and O(V) extra space beyond adjacency. A short result proves a cycle. Initialize isolated vertices too. In a strictly increasing grid graph, edges from lower to higher values cannot cycle; counting frozen BFS layers gives the longest path length. Duplicate edges must be counted and removed consistently. Practice: 210 Course Schedule II, 329 Increasing Matrix Path.

Union find¶

Track components while undirected edges arrive. An edge whose endpoints already share a representative creates a cycle. Choose either union by size (component cardinality) or union by rank (a bound on tree height). Both versions below use iterative path halving and return False when an edge joins vertices that are already connected.

class DisjointSet:
    def __init__(self, count):
        self.parent = list(range(count))
        self.size = [1] * count

    def find(self, node):
        while node != self.parent[node]:
            self.parent[node] = self.parent[self.parent[node]]
            node = self.parent[node]
        return node

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True


class DisjointSetByRank:
    def __init__(self, count):
        self.parent = list(range(count))
        self.rank = [0] * count

    def find(self, node):
        while node != self.parent[node]:
            self.parent[node] = self.parent[self.parent[node]]
            node = self.parent[node]
        return node

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.rank[a] < self.rank[b]:
            a, b = b, a
        self.parent[b] = a
        if self.rank[a] == self.rank[b]:
            self.rank[a] += 1
        return True

Invariant: each parent tree represents one component; only roots own meaningful size values. Path compression plus union by size gives amortized O(alpha(V)) per operation after O(V) initialization, with O(V) storage. Union by rank has the same bounds when combined with path compression. Attach the lower-rank root below the higher-rank root; increment the surviving root's rank only when two distinct roots have equal rank. A duplicate union must not increment rank. Compression can shorten paths, so rank is a historical upper bound on height, not the current height and not the component size. Do not reduce rank during find. Without compression, union by rank alone gives O(log V) worst-case find/union time; the compressed bound is amortized, not constant worst-case time for each call.

Example: union(0,1) makes root 0 rank 1, and union(2,3) makes root 2 rank 1. Then union(0,2) makes root 0 rank 2. Finding 3 shortens its path to root 0, but rank 2 stays unchanged. Use size when you also need component cardinality; rank alone cannot answer that query. This structure answers connectivity, not directed cycle detection or shortest paths. Practice: 684 Redundant Connection.

Dijkstra¶

Use a min-heap of tentative distances for nonnegative weighted edges. A later improvement leaves old heap entries behind; skip those stale entries.

from heapq import heappop, heappush


def shortest_distances(adjacency, start):
    distances = [float("inf")] * len(adjacency)
    distances[start] = 0
    heap = [(0, start)]
    while heap:
        distance, node = heappop(heap)
        if distance != distances[node]:
            continue
        for child, weight in adjacency[node]:
            candidate = distance + weight
            if candidate < distances[child]:
                distances[child] = candidate
                heappush(heap, (candidate, child))
    return distances

Invariant: the next nonstale minimum distance is settled; nonnegative edges cannot create a shorter route through an unsettled larger-distance node. The lazy-heap version takes O(V + E log(E+2)) time and O(V+E) space including heap entries. Infinity identifies unreachable nodes. Zero-weight edges are valid; negative weights invalidate this proof. Practice: 743 Network Delay.

Euler trails¶

When every directed ticket must be used once, find an Euler trail over edges. Hierholzer's algorithm records a vertex only after all its outgoing edges are used.

from collections import defaultdict


def itinerary(tickets, start):
    graph = defaultdict(list)
    for origin, destination in sorted(tickets, reverse=True):
        graph[origin].append(destination)
    stack, reversed_route = [start], []
    while stack:
        node = stack[-1]
        if graph[node]:
            stack.append(graph[node].pop())
        else:
            reversed_route.append(stack.pop())
    return reversed_route[::-1]

Invariant: exhausted walks are spliced into the final edge-using trail by reverse postorder. The input must promise an Euler trail from start. Reverse-sorted destination lists pop the lexicographically smallest edge first; postorder handles dead ends that a direct greedy output would mishandle. O(E log E) sorting time, O(E) traversal time and storage. Use lists, so repeated tickets remain edges. Practice: 332 Reconstruct Itinerary.

Linear DP¶

Define what one prefix or total represents before writing a transition. Only discard older states when all dependencies are accounted for.

def nonadjacent_maximum(values):
    two_back = one_back = 0
    for value in values:
        two_back, one_back = one_back, max(one_back, two_back + value)
    return one_back


def minimum_coins(coins, amount):
    impossible = amount + 1
    dp = [0] + [impossible] * amount
    for total in range(1, amount + 1):
        for coin in coins:
            if coin <= total:
                dp[total] = min(dp[total], dp[total - coin] + 1)
    return -1 if dp[amount] > amount else dp[amount]

Robber invariant: one_back is the best processed prefix and two_back is the previous prefix. O(n) time, O(1) space. Coin invariant: dp[total] is the minimum count for exactly total; positive coins make earlier totals sufficient. O(amount * coin_count) time and O(amount) space. For circular robbery exclude one endpoint in each of two linear runs. Word Break uses reachable prefix lengths: a reachable start plus a dictionary substring makes its end reachable. If substring lengths are bounded by L, direct Python slicing/hash checks cost up to O(n * L^2), not just O(nL). Practice: 198 House Robber, 322 Coin Change, 139 Word Break.

DP space optimization¶

Space compression discards obsolete rows; bitmask state compression instead encodes which objects belong to a subset. They solve different problems and can coexist. First write the full recurrence D[i][c], then label every dependency as previous row or current row. Do not choose loop direction by memorizing "DP goes backward".

For 0/1 knapsack, D[i][c] = max(D[i-1][c], D[i-1][c-w]+v): both reads must remain from the previous row, so capacities descend. Unbounded knapsack uses D[i][c-w] instead, so capacities ascend and may reuse the current item. Both functions below maximize value with total weight at most capacity; they require nonnegative capacity and positive integer weights. Empty selection is allowed.

def knapsack_once(items, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in items:
        for total in range(capacity, weight - 1, -1):
            dp[total] = max(dp[total], dp[total - weight] + value)
    return dp[capacity]


def knapsack_unbounded(items, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in items:
        for total in range(weight, capacity + 1):
            dp[total] = max(dp[total], dp[total - weight] + value)
    return dp[capacity]

Invariant: descending updates preserve the previous item's row at lower capacities; ascending updates deliberately expose the current item's row there. For the single item (weight=2, value=3), capacity=4 gives 3 for 0/1 and 6 for unbounded. Reversing these loops silently changes the problem. Both use O(item_count * capacity) time and O(capacity) space instead of O(item_count * capacity) space.

Grid DP needs old top and new left, so scan left-to-right. String edit distance also needs old top-left: save old dp[j] before overwriting it, then carry that as the next diagonal (see the executable String DP example). Reset the left boundary each row. Distinct subsequences instead scans target positions right-to-left so one source character cannot be used twice. Exact-fill variants need unreachable sentinels, not this at-most-capacity initialization. Counting variants must distinguish combinations from ordered sequences before reordering loops. Compression may lose reconstruction information; retain parents or rows when the actual choices are required. Practice: 416 Equal Subset Sum, 322 Coin Change, 72 Edit Distance.

LIS¶

Maintain the smallest achievable last value for each increasing subsequence length. Binary search where a new value can replace or extend those tails.

from bisect import bisect_left


def increasing_length(values):
    tails = []
    for value in values:
        index = bisect_left(tails, value)
        if index == len(tails):
            tails.append(value)
        else:
            tails[index] = value
    return len(tails)

Invariant: tails[i] is the smallest possible ending value for length i+1. O(n log n) time and O(n) space. bisect_left gives strict increase; bisect_right would allow equal values. The tails list gives the correct length, but is not necessarily one actual subsequence; reconstruction requires predecessors. Practice: 300 Longest Increasing Subsequence.

Grid DP¶

For right/down movement, each cell depends only on its top and left neighbors. A one-row array keeps the old top and the newly computed left.

def count_grid_paths(rows, cols):
    dp = [1] * cols
    for _ in range(1, rows):
        for col in range(1, cols):
            dp[col] += dp[col - 1]
    return dp[-1]


def minimum_grid_cost(grid):
    cols = len(grid[0])
    dp = [float("inf")] * cols
    dp[0] = 0
    for row in grid:
        for col, cost in enumerate(row):
            left = dp[col - 1] if col else float("inf")
            dp[col] = cost + min(dp[col], left)
    return dp[-1]

Invariant: before updating a column, dp[col] is its top result; afterward it is the current cell result. Both use O(rows * cols) time and O(cols) auxiliary space and require a nonempty grid. Counts combine by addition; costs combine by minimum then add the current value. Initialize the starting cell only once. Practice: 62 Unique Paths, 64 Minimum Path Sum.

String DP¶

Use prefix lengths as coordinates. A compressed row needs the previous diagonal saved before its current cell is overwritten.

def edit_distance(a, b):
    dp = list(range(len(b) + 1))
    for i, char_a in enumerate(a, 1):
        diagonal, dp[0] = dp[0], i
        for j, char_b in enumerate(b, 1):
            above = dp[j]
            if char_a == char_b:
                dp[j] = diagonal
            else:
                dp[j] = 1 + min(above, dp[j - 1], diagonal)
            diagonal = above
    return dp[-1]

Invariant: above belongs to the previous row, left to the current row, and diagonal to the previous row and column. O(mn) time and O(n) space here.

Interval DP¶

Choose the last action in an interval when choosing the first would change its neighbors. Open endpoints remain fixed until every interior item is removed.

def balloon_score(nums):
    values = [1, *nums, 1]
    size = len(values)
    dp = [[0] * size for _ in range(size)]
    for gap in range(2, size):
        for left in range(size - gap):
            right = left + gap
            dp[left][right] = max(
                dp[left][last] + dp[last][right] + values[left] * values[last] * values[right]
                for last in range(left + 1, right)
            )
    return dp[0][-1]

Invariant: smaller open intervals are complete before a larger one. If last is burst last, its neighbors are exactly the fixed endpoints, so the two remaining intervals are independent. O(n^3) time and O(n^2) space. Sentinel ones model outside boundaries; do not count them as balloons. Practice: 312 Burst Balloons.

State machine DP¶

When actions change a finite status, name each allowed status explicitly. For at most two stock transactions, track first buy/sell and second buy/sell.

def two_transaction_profit(prices):
    buy1 = buy2 = float("-inf")
    sell1 = sell2 = 0
    for price in prices:
        buy1, sell1, buy2, sell2 = (
            max(buy1, -price),
            max(sell1, buy1 + price),
            max(buy2, sell1 - price),
            max(sell2, buy2 + price),
        )
    return sell2

Invariant: each state is the best cash balance achievable in that status after the processed days. Tuple assignment reads previous-day values for all transitions. Sell states start at zero to allow fewer than two transactions; buy states start unreachable. O(n) time and O(1) space. Never hold more than one stock at a time. Practice: 123 Stock III.

Matrix simulation¶

Write the coordinate mapping before moving values. A clockwise square rotation maps (row,col) to (col,n-1-row); transpose followed by row reversal implements it.

def rotate_clockwise(matrix):
    size = len(matrix)
    for row in range(size):
        for col in range(row + 1, size):
            matrix[row][col], matrix[col][row] = matrix[col][row], matrix[row][col]
    for row in matrix:
        row.reverse()

Matrix prefix sums¶

An extra zero row and column let every rectangular sum use the same formula. Use half-open query boundaries to make sizes and empty prefixes explicit.

def matrix_prefix(grid):
    rows, cols = len(grid), len(grid[0])
    prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
    for row in range(rows):
        for col in range(cols):
            prefix[row + 1][col + 1] = (
                grid[row][col] + prefix[row][col + 1] + prefix[row + 1][col] - prefix[row][col]
            )
    return prefix


def rectangle_sum(prefix, top, left, bottom, right):
    return prefix[bottom][right] - prefix[top][right] - prefix[bottom][left] + prefix[top][left]

Invariant: prefix[r][c] sums the first r rows and the first c columns. Construction takes O(rows*cols) time/space; each valid rectangle query takes O(1). Bit manipulation¶

State the word width and signed interpretation. Python integers do not overflow at 32 bits, so signed-word algorithms must mask intermediate states explicitly.

def signed_word_add(a, b, width=32):
    mask = (1 << width) - 1
    a, b = a & mask, b & mask
    while b:
        a, b = (a ^ b) & mask, ((a & b) << 1) & mask
    sign = 1 << (width - 1)
    return a if a < sign else a - (1 << width)

XOR is the sum without carries; AND shifted left is the carry. The loop takes O(width) bounded-word operations and O(1) word storage. For a single isolated set bit use value & -value. For a range AND, retain only the common high prefix. For two unique values among pairs, XOR all values and use one differing bit to partition the two singletons. Arbitrary large-integer operations have bit costs. Practice: 371 Sum of Two Integers, 260 Single Number III.

Integer arithmetic¶

Reduce a large exponent by squaring rather than repeating one multiplication for every unit of the exponent.

def nonnegative_power(base, exponent):
    result = 1
    while exponent:
        if exponent & 1:
            result *= base
        base *= base
        exponent >>= 1
    return result

Invariant: result times base raised to the remaining exponent equals the target. O(log(exponent+1)) arithmetic operations and O(1) auxiliary variables for a nonnegative integer exponent. Negative exponents use a reciprocal when permitted. Exact integer division can instead subtract shifted divisors; truncation toward zero needs sign restoration. Fenwick tree¶

A Fenwick node at one-based index i summarizes the interval of length i & -i ending at i. Updates climb through containing intervals; prefix queries remove the last covered interval.

class Fenwick:
    def __init__(self, size):
        self.tree = [0] * (size + 1)

    def add(self, index, delta):  # 1 <= index < len(tree)
        while index < len(self.tree):
            self.tree[index] += delta
            index += index & -index

    def prefix(self, index):  # Sum of positions 1..index; index 0 is valid.
        total = 0
        while index:
            total += self.tree[index]
            index -= index & -index
        return total

O(log n) per update/query and O(n) storage. A range sum is prefix(right) minus prefix(left-1). Use coordinate compression when indices are arbitrary values; compression preserves order, not distances. Counting strictly smaller values queries rank-1 before inserting the current rank. Updating index zero is invalid. Practice: 307 Mutable Range Sum, 315 Count Smaller.

Segment tree¶

Store an associative aggregate for each interval. This iterative sum tree uses leaves at indices n..2n and half-open query ranges.

class SumTree:
    def __init__(self, values):
        self.size = len(values)
        self.tree = [0] * self.size + list(values)
        for node in range(self.size - 1, 0, -1):
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]

    def assign(self, index, value):
        node = index + self.size
        self.tree[node] = value
        while node > 1:
            node //= 2
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]

    def query(self, left, right):
        left, right = left + self.size, right + self.size
        total = 0
        while left < right:
            if left & 1:
                total += self.tree[left]
                left += 1
            if right & 1:
                right -= 1
                total += self.tree[right]
            left //= 2
            right //= 2
        return total

For a nonempty input: O(n) construction/storage and O(log n) update/query. Every tree entry remains the sum of its children. Range-add/range-maximum problems need a different aggregate and lazy propagation; an enormous coordinate domain can use dynamically allocated nodes rather than a full domain array. Practice: 307 Mutable Range Sum, 732 My Calendar III.

Sweep line¶

Convert intervals into start/end events and process coordinates in order. For half-open intervals, combine all changes at the same coordinate before observing the active count.

from collections import defaultdict


def peak_overlap(intervals):
    changes = defaultdict(int)
    for start, end in intervals:
        changes[start] += 1
        changes[end] -= 1
    active = peak = 0
    for position in sorted(changes):
        active += changes[position]
        peak = max(peak, active)
    return peak

Invariant: active is the number of intervals covering the next coordinate span. O(n log n) time and O(n) space. Merge sort counting¶

Sorted halves allow a monotone scan of cross-half relationships while merging. This skeleton counts inversions without changing its input.

def inversion_count(values):
    def visit(items):
        if len(items) < 2:
            return items[:], 0
        middle = len(items) // 2
        left, first = visit(items[:middle])
        right, second = visit(items[middle:])
        merged = []
        i = j = 0
        count = first + second
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i])
                i += 1
            else:
                count += len(left) - i
                merged.append(right[j])
                j += 1
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged, count

    return visit(values)[1]

O(n log n) time and O(n) peak auxiliary storage. Each strict inversion crossing the split is counted exactly when its right value is merged before larger left values. For range-sum counts, sort prefix sums and maintain two monotone bounds for lower<=right_prefix-left_prefix<=upper. Retain original indices when output belongs to individual array positions. Practice: 315 Count Smaller, 327 Count of Range Sum.

Bitmask DP¶

State compression here encodes a subset as an integer bitmask; it does not mean discarding DP rows (see the DP space optimization template). When there are few items, a mask records exactly which ones have been used. For equal-sum grouping of positive values, the used mask determines the current bucket remainder. A state may be merged only if all future choices are identical: a route DP often needs (mask, last_vertex), not just mask. There are still 2^n subsets; compact representation does not remove exponential state growth.

def equal_sum_groups(values, groups):
    total = sum(values)
    if total % groups:
        return False
    target = total // groups
    remainder = [-1] * (1 << len(values))
    remainder[0] = 0
    for mask in range(1 << len(values)):
        if remainder[mask] < 0:
            continue
        for index, value in enumerate(values):
            if mask & (1 << index) or remainder[mask] + value > target:
                continue
            following = mask | (1 << index)
            remainder[following] = (remainder[mask] + value) % target
    return remainder[-1] == 0

Invariant: a reachable mask fills complete buckets plus the stored remainder. Values and group count must be positive, making target positive when divisible. O(n * 2^n) time and O(2^n) space. A mask is exact item identity, so duplicates at different indices remain separate items. For subset-sum feasibility, a Python integer bitset is another representation: bits |= bits << value, with cost depending on the bitset length. Practice: 698 Equal-Sum Subsets, 416 Equal Subset Sum.

Digit DP¶

Count integers by building their decimal digits while tracking only information that affects future choices. This executable example counts numbers in [0, bound] with no repeated significant digit. State is (position, used_mask, tight, started): tight means the prefix still equals the bound, and started distinguishes padding zeros from actual digits. Zero itself is included once by the terminal policy.

from functools import cache


def count_unique_digits_up_to(bound):
    if bound < 0:
        return 0
    digits = tuple(map(int, str(bound)))

    @cache
    def visit(position, used_mask, tight, started):
        if position == len(digits):
            return 1  # Includes the all-padding path as the integer zero.
        limit = digits[position] if tight else 9
        total = 0
        for digit in range(limit + 1):
            next_tight = tight and digit == digits[position]
            if not started and digit == 0:
                total += visit(position + 1, used_mask, next_tight, False)
            elif not used_mask & (1 << digit):
                total += visit(position + 1, used_mask | (1 << digit), next_tight, True)
        return total

    return visit(0, 0, True, False)


def count_unique_digits_between(left, right):
    if left < 0 or right < left:
        raise ValueError("Require 0 <= left <= right")
    return count_unique_digits_up_to(right) - count_unique_digits_up_to(left - 1)

Invariant: each state counts valid suffixes for exactly its prefix restrictions. A leading zero does not occupy bit 0; after starting, zero is a real digit and cannot repeat. For bound=20, only 11 is excluded, so the count is 20. For bound=0, the answer is 1. To exclude zero, the terminal return must be int(started); for other digit properties, explicitly decide whether zero satisfies the property. Never mark padding zeros as used, and never drop tight or other future-relevant state from a shared cache key. The cache is local to each bound, so calls for R and L-1 cannot contaminate one another. Caching tight states here is safe; an alternative is to memoize only unrestricted (not tight) states. Count an inclusive interval with F(R)-F(L-1), defining F(-1)=0, not F(R)-F(L).

For D decimal digits and S property states, the general bound is O(D * S * 10) time and O(D * S) cache space, plus O(D) recursion depth; here S is at most 2^10 masks times constant Boolean flags. These are arithmetic-operation bounds; large integer counts have additional bit costs. This recursive teaching snippet is for ordinary integer bounds, not arbitrarily long decimal strings. Digit-sum or divisibility variants replace/extend used_mask with a sum or remainder and adjust terminal acceptance; they must still retain tight and leading-zero semantics. Practice: 357 Count Numbers with Unique Digits is the special range [0, 10^n-1]; this template generalizes it to arbitrary bounds.

Minimum spanning tree¶

Connect all vertices with minimum total edge weight. Sort edges by weight and accept only edges joining different components.

def spanning_tree_cost(vertex_count, weighted_edges, components):
    # components is a fresh DisjointSet(vertex_count).
    total = used = 0
    for weight, a, b in sorted(weighted_edges):
        if components.union(a, b):
            total += weight
            used += 1
    return total if used == vertex_count - 1 else None

Invariant: the selected edges form a forest extendable to a minimum spanning tree; the lightest edge crossing two components is safe by the cut property. O(E log E) sorting time plus near-linear union operations; O(V+E) storage. Prim instead grows one connected frontier. For dense implicit graphs such as all pairwise Manhattan distances, an O(V^2)-time array implementation of Prim uses O(V) state without constructing every edge. State space search¶

A location is not always the full state. Remaining resources, visited vertices, or collected keys can change which moves are possible from that same location.

from collections import deque


def shortest_state_path(starts, neighbors, goal):
    distances = {state: 0 for state in starts}
    queue = deque(distances)
    while queue:
        state = queue.popleft()
        if goal(state):
            return distances[state]
        for following in neighbors(state):
            if following in distances:
                continue
            distances[following] = distances[state] + 1
            queue.append(following)
    return -1

Invariant: each complete state has its shortest unweighted distance on first discovery. With RC cells and K keys, the state bound is O(RC2^K), not O(RC). Use (node,visited_mask) for visiting every vertex and seed every start node when the start is free to choose. A cell-only visited set can discard essential revisits after acquiring a key. Bridge finding¶

For an undirected simple graph, a DFS tree edge parent->child is a bridge exactly when the child's subtree has no route to the parent or an earlier ancestor. Explicit iterators preserve recursive DFS entry/exit order.

def graph_bridges(adjacency):
    size = len(adjacency)
    entered = [-1] * size
    low = [0] * size
    parent = [-1] * size
    clock = 0
    result = []
    for start in range(size):
        if entered[start] != -1:
            continue
        entered[start] = low[start] = clock
        clock += 1
        stack = [(start, iter(adjacency[start]))]
        while stack:
            node, edges = stack[-1]
            child = next(edges, None)
            if child is None:
                stack.pop()
                above = parent[node]
                if above != -1:
                    if low[node] > entered[above]:
                        result.append((above, node))
                    low[above] = min(low[above], low[node])
                continue
            if child == parent[node]:
                continue
            if entered[child] != -1:
                low[node] = min(low[node], entered[child])
                continue
            parent[child] = node
            entered[child] = low[child] = clock
            clock += 1
            stack.append((child, iter(adjacency[child])))
    return result

Invariant: low[node] is the earliest discovery reachable through its finished DFS subtree plus at most one non-parent back edge. O(V+E) time and O(V) traversal space. This skeleton assumes integer vertices and no parallel edges; multigraphs must identify the parent edge by edge ID. Iteration avoids recursion failure on a 100,000-node chain. Practice: 1192 Critical Connections.

Prefix function¶

The prefix function stores the longest proper prefix that is also a suffix of each processed prefix. Reuse the previous border before trying smaller ones.

def prefix_function(text):
    prefix = [0] * len(text)
    for index in range(1, len(text)):
        length = prefix[index - 1]
        while length and text[index] != text[length]:
            length = prefix[length - 1]
        if text[index] == text[length]:
            length += 1
        prefix[index] = length
    return prefix

Invariant: length is a candidate border of the prefix ending before the new character. Fallback follows already-proved shorter borders. Total time is O(n) because increases and decreases of the candidate length amortize; storage is O(n). For a nonempty string, text[:prefix[-1]] is its longest proper border. Prefix and suffix may overlap. KMP uses the same failure links while scanning a second string. Practice: 1392 Longest Happy Prefix.

Z function¶

For i>0, Z[i] is the common-prefix length between the full string and the suffix starting at i; this convention leaves Z[0]=0. Reuse matches inside the current rightmost known matching interval.

def z_function(text):
    z = [0] * len(text)
    left = right = 0
    for index in range(1, len(text)):
        if index <= right:
            z[index] = min(right - index + 1, z[index - left])
        while index + z[index] < len(text) and text[z[index]] == text[index + z[index]]:
            z[index] += 1
        if index + z[index] - 1 > right:
            left, right = index, index + z[index] - 1
    return z

Invariant: text[left:right+1] matches the same-length prefix and reaches the farthest known right endpoint. New comparisons extend that endpoint, giving O(n) total time and O(n) storage. A proper border begins at i>0 with i+Z[i]==n. Both Z and prefix-function solutions are deterministic, avoiding hash collisions. Practice: 1392 Longest Happy Prefix.

Custom sorting¶

Choose the comparison that corresponds to the output objective. For concatenated numbers, compare a+b with b+a rather than their numeric values or lengths.

from functools import cmp_to_key


def largest_concatenation(values):

Randomized sampling¶

Reservoir sampling chooses uniformly among matching items without storing all their positions. The RNG is supplied so tests can control its state.

def reservoir_index(values, target, rng):
    answer = None
    matches = 0
    for index, value in enumerate(values):
        if value != target:
            continue
        matches += 1
        if rng.randrange(matches) == 0:
            answer = index
    return answer

After t matches, each match has probability 1/t: a prior choice survives with (t-1)/t and the new match is chosen with 1/t. O(n) query time and O(1) space. A precomputed position map trades O(n) storage for O(1) sampling queries. Fisher-Yates shuffling chooses uniformly from the remaining prefix at each swap. Circular buffers¶

Store only head and size; derive the next insertion position modulo capacity. This avoids independent head/tail flags representing inconsistent states.

class RingQueue:
    def __init__(self, capacity):
        self.data = [0] * capacity
        self.head = 0
        self.size = 0

    def enqueue(self, value):
        if self.size == len(self.data):
            return False
        index = (self.head + self.size) % len(self.data)
        self.data[index] = value
        self.size += 1
        return True

    def dequeue(self):
        if self.size == 0:
            return False
        self.head = (self.head + 1) % len(self.data)
        self.size -= 1
        return True

    def front(self):
        return self.data[self.head] if self.size else -1

Invariant: 0<=size<=capacity and live entries occupy size consecutive cyclic positions from head. Capacity is positive. Operations take O(1) time; storage is O(capacity). Empty/full depend on size, so equal cyclic indices are unambiguous. Practice: 622 Circular Queue.

Matrix exponentiation¶

Use this when a fixed linear transition updates a small vector of counts and the number of repetitions is large. Define transition[destination][source] as the number of ways to move between those states in one step. The matrix must be square, its size must match counts, steps must be nonnegative, and modulus must be positive.

def advance_states(transition, counts, steps, modulus):
    size = len(counts)
    power = transition
    result = [count % modulus for count in counts]
    while steps:
        if steps & 1:
            result = [
                sum(power[row][col] * result[col] for col in range(size)) % modulus
                for row in range(size)
            ]
        power = [
            [
                sum(power[row][mid] * power[mid][col] for mid in range(size)) % modulus
                for col in range(size)
            ]
            for row in range(size)
        ]
        steps >>= 1
    return result

Invariant: power represents the current power-of-two number of transitions; result has already applied the powers corresponding to consumed set bits. Squaring doubles the represented length, and a set bit applies that block to the current counts. No input list is modified.

For transition=[[1,1],[1,0]], counts=[1,0], and four steps, the result is [5,3], the corresponding adjacent Fibonacci numbers. Zero steps returns the initial vector modulo modulus.

For d states and t>0 steps, time is O(d^3 log(t+1)) and space is O(d^2). Zero steps costs O(d). These are arithmetic-operation bounds; with a fixed modulus and fixed small d, integer sizes remain bounded. Use rolling DP when t is modest: matrix multiplication has a larger constant factor. Ensure the transition direction matches destination rows, and count extensions correctly: a length-one initialization needs n-1 extensions, while an empty initialization needs n.

Python costs to remember¶

  • A list append is amortized O(1); removing index 0 shifts elements. Use deque for queue operations at the front.
  • Slicing a string or list copies the slice. Hashing a newly created string also reads its characters. Include those costs in Word Break and Word Ladder.
  • Sorting a copy and Python sorting workspace can use O(n) extra memory.
  • Use a comprehension for independent nested lists. Repeated references to one inner list make table updates affect several rows.
  • Heap entries must remain comparable on ties; put a unique numeric index before a node object. Do not assume heap order is full sorted order.
  • Ordinary dictionaries and sets give expected constant-time lookup for small keys. Store frequencies, first indices, or object identities according to the invariant the problem needs.
  • Integer arithmetic in these analyses uses the usual bounded-number interview model. Very large Python integers have costs proportional to their bit length.
  • Prefer iterative traversal when a valid tree, graph, or grid path can exceed Python's recursion limit. Bounded-depth backtracking can remain recursive.
